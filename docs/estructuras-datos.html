4  Estructuras de datos: listas, tuplas y diccionarios

Una variable guarda un valor. Pero en la práctica manejas colecciones: las lecturas de un sensor durante el día, los precios de 20 productos, las coordenadas de las parcelas. Para eso existen las estructuras de datos. En este capítulo verás las tres esenciales: listas, tuplas y diccionarios.

4.1 Listas: colecciones ordenadas que puedes modificar

Una lista es una secuencia de valores entre corchetes [], separados por comas:

lecturas = [22.5, 23.1, 24.0, 23.8, 25.2]  # temperaturas de un sensor
print(lecturas)
[22.5, 23.1, 24.0, 23.8, 25.2]

4.1.1 Acceder a un elemento: los índices empiezan en cero

Cada elemento tiene una posición llamada índice. La regla que confunde a todo principiante: el primer elemento es el índice 0, no el 1:

lecturas = [22.5, 23.1, 24.0, 23.8, 25.2]

print(lecturas[0])   # primera lectura
print(lecturas[2])   # tercera lectura
print(lecturas[-1])  # última lectura (el -1 cuenta desde el final)
22.5
24.0
25.2

4.1.2 Modificar, agregar y contar

Las listas son mutables: puedes cambiarlas después de crearlas:

precios = [9500, 8200, 10500]

precios[0] = 9800        # modificar: el primer precio cambió
precios.append(7600)     # agregar al final
print(precios)
print(len(precios))      # cuántos elementos tiene
[9800, 8200, 10500, 7600]
4

4.1.3 Operaciones útiles sin escribir ciclos

Python trae funciones que resumen una lista en una línea:

producciones = [4.2, 3.8, 5.1, 4.6, 3.9]

print(sum(producciones))   # total
print(max(producciones))   # la mayor
print(min(producciones))   # la menor
print(len(producciones))   # cuántas parcelas
print(sum(producciones) / len(producciones))  # promedio
21.599999999999998
5.1
3.8
5
4.319999999999999

4.1.4 Rebanadas (slicing): tomar una parte

Con [inicio:fin] tomas un pedazo de la lista (incluye el inicio, no incluye el fin):

lecturas = [22.5, 23.1, 24.0, 23.8, 25.2]

print(lecturas[1:3])   # del índice 1 al 2
print(lecturas[:2])    # las dos primeras
print(lecturas[3:])    # del índice 3 al final
[23.1, 24.0]
[22.5, 23.1]
[23.8, 25.2]

4.1.5 Recorrer una lista

Ya lo hiciste en el capítulo anterior: el for nació para esto:

ventas = [12.5, 15.2, 9.8, 18.1]  # millones por trimestre

for v in ventas:
    if v < 10:
        print(f"Trimestre bajo: {v}")
Trimestre bajo: 9.8

4.2 Tuplas: colecciones que no deben cambiar

Una tupla se escribe con paréntesis () y es inmutable: una vez creada, no se puede modificar. Sirve para datos que conceptualmente van juntos y no deben alterarse, como las coordenadas de una parcela:

ubicacion = (3.42, -76.53)  # latitud, longitud

print(ubicacion[0])  # latitud
3.42

Si intentas modificarla, Python te protege con un error:

ubicacion[0] = 4.0   # TypeError: las tuplas no se modifican
TypeError: 'tuple' object does not support item assignment

Regla práctica: si los datos representan algo fijo (coordenadas, una fecha, un registro que no debe tocarse), usa tupla. Si van a cambiar (lecturas, precios, inventarios), usa lista.

4.3 Diccionarios: datos con nombre, no con posición

En una lista accedes por posición (precios[0]). Pero ¿y si quieres acceder por nombre? Para eso están los diccionarios: pares de clave y valor entre llaves {}:

precios = {
    "café": 9500,
    "cacao": 8200,
    "banano": 7600
}

print(precios["café"])   # acceder por clave
9500

Agregar y modificar es asignar a una clave:

precios = {"café": 9500, "cacao": 8200, "banano": 7600}

precios["banano"] = 7800      # modificar
precios["panela"] = 5200      # agregar un producto nuevo
print(precios)
{'café': 9500, 'cacao': 8200, 'banano': 7800, 'panela': 5200}

Recorrer un diccionario con .items() te da clave y valor a la vez:

inventario = {"motobombas": 3, "sensores_humedad": 12, "valvulas": 25}

for equipo, cantidad in inventario.items():
    if cantidad < 5:
        print(f"Reponer {equipo}: quedan {cantidad}")
Reponer motobombas: quedan 3

4.3.1 Un diccionario puede guardar una ficha completa

Los diccionarios brillan cuando un valor es a su vez otra estructura:

empleado = {
    "nombre": "María Pérez",
    "cargo": "Analista",
    "salario": 2800000,
    "areas": ["compras", "logística"]
}

print(empleado["nombre"])
print(empleado["salario"] * 12)   # salario anual
María Pérez
33600000

Este patrón — una ficha con campos nombrados — es la base de casi todo el manejo de datos que verás en el capítulo de pandas.

4.4 ¿Cuál estructura usar?

Estructura Sintaxis ¿Se modifica? Acceso por Úsala para
Lista [1, 2, 3] Sí Posición Series de mediciones, colecciones que crecen
Tupla (1, 2) No Posición Datos fijos que van juntos (coordenadas)
Diccionario {"a": 1} Sí Nombre (clave) Fichas, inventarios, catálogos, configuración

4.5 Ejercicios

  1. Crea una lista con las temperaturas de 7 días. Imprime la máxima, la mínima y el promedio (con sum y len).
  2. De la lista costos = [45000, 120000, 38000, 90000, 67000], imprime solo los costos mayores a 50000 usando un for y un if.
  3. Crea una tupla con la coordenada de tu ciudad y otra con la de una finca. Imprime la diferencia de latitud entre ambas.
  4. Crea un diccionario con 4 productos agrícolas y sus precios. Sube todos los precios un 10 % recorriéndolo con .items() y reasignando cada valor.
  5. Crea un diccionario que represente un sensor con las claves id, tipo, parcela y lecturas (una lista de 5 valores). Imprime el promedio de sus lecturas accediendo a través del diccionario.
  6. Mini-reto (administración): tienes esta lista de ventas mensuales (millones): [42, 38, 55, 61, 47, 39, 52, 58, 63, 49, 44, 57]. Sin usar funciones hechas, solo un for y acumuladores: calcula el promedio anual, cuenta cuántos meses superaron el promedio e imprime ambos resultados. Luego, guarda en un diccionario resumen las claves "promedio" y "meses_sobre_promedio".

4.6 Resumen

  • Lista []: ordenada y modificable; el caballo de batalla. Índices desde 0.
  • append() agrega, len() cuenta, sum()/max()/min() resumen, [i:j] rebana.
  • Tupla (): igual a la lista pero inmutable; para datos fijos.
  • Diccionario {}: pares clave-valor; acceso por nombre con d["clave"], recorrido con .items().
  • Elegir bien la estructura es la mitad del programa.
